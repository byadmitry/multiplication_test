# ✕ Таблица умножения и ÷ деления

Небольшое автономное веб-приложение для тренировки таблицы умножения и связанных с ней примеров на деление.

Приложение не требует установки, сервера, Node.js, Python или других зависимостей: достаточно открыть `multiplication_test.html` в современном браузере на Windows 11.

## Возможности

- 🎯 Настраиваемое количество вопросов.
- ✕ Примеры на умножение чисел от **1 до 9**.
- ÷ Примеры на деление результатов умножения чисел от **1 до 9** с целым результатом от 1 до 9.
- 🔀 Случайный порядок вопросов.
- 🚫 Без повторяющихся заданий в рамках одного теста.
  - `2 × 3` и `3 × 2` считаются одним и тем же фактом умножения и повторно не выдаются.
  - Для деления одинаковые выражения также не повторяются.
- 🧠 При ошибке автоматически добавляются **2 новых уникальных вопроса**, если такие задания ещё остались.
- 👀 На экране одновременно отображается **только один текущий вопрос**.
- 📊 Живой прогресс: сколько вопросов пройдено и сколько осталось.
- ⏹ Возможность завершить тест досрочно.
- 🏁 Автоматическое завершение после ответа на последний вопрос.
- 📈 Итоговая статистика:
  - всего вопросов;
  - правильных ответов;
  - неправильных ответов;
  - процент правильных ответов.
- 📝 Подробный протокол прохождения теста.
- 💾 Экспорт протокола в обычный `.txt` файл.
- ⌨️ Ответ можно отправлять клавишей **Enter**.
- 📱 Адаптивная вёрстка для небольших экранов.
- 🌙 Тёмный интерфейс без внешних библиотек и CDN.

## Как запустить

1. Скачайте репозиторий.
2. Откройте файл `multiplication_test.html` двойным щелчком.
3. Приложение откроется непосредственно в браузере.

Сервер для запуска не нужен.

## Как проходит тест

### 1. Настройка

На стартовой форме задаётся количество исходных вопросов. Можно выбрать один или оба типа заданий:

- умножение;
- деление.

Количество ограничивается числом доступных уникальных заданий для выбранных типов.

### 2. Прохождение

Вопросы заранее перемешиваются, но на форме показывается только **один вопрос за раз**. После ответа приложение показывает результат и автоматически переходит к следующему заданию.

Для каждого вопроса отображается выражение, знак `=` и одно поле для ответа.

После отправки ответа приложение сразу показывает результат:

- `✓` — ответ правильный;
- `✗` — ответ неправильный, рядом показывается правильный результат.

При неправильном ответе в конец очереди добавляются два новых задания, которых пользователь ещё не видел. Если осталось только одно уникальное задание, добавляется одно; если уникальных заданий больше нет, дополнительные вопросы не добавляются.

### 3. Завершение

Тест заканчивается автоматически после ответа на последний доступный вопрос, либо вручную по кнопке **«Завершить»**.

При досрочном завершении неотвеченные вопросы считаются неправильными. Это отражается и в статистике, и в протоколе.

## Уникальность вопросов

Приложение формирует конечный пул заданий перед началом теста и удаляет выданные задания из очереди. Поэтому одно и то же задание не может появиться повторно в рамках одной сессии.

Для умножения коммутативные варианты считаются одним заданием: `2 × 3` и `3 × 2` не выдаются как два разных вопроса. Таким образом, доступно **45 уникальных фактов умножения**.

Для деления формируются задания вида `a × b ÷ a` и `a × b ÷ b`, сведённые к уникальным выражениям `делимое ÷ делитель`, где результат находится от 1 до 9. Всего доступно **81 уникальное задание на деление**.

При выборе обоих типов максимально доступно **126 уникальных заданий**.

## Прогресс

В верхней части теста отображаются:

- количество уже пройденных вопросов;
- количество оставшихся вопросов;
- процент выполнения;
- графическая шкала прогресса.

Если из-за ошибки добавляются новые задания, общее количество и оставшееся количество автоматически увеличиваются.

## Протокол

Протокол содержит:

- дату и время прохождения;
- общее количество вопросов;
- количество правильных и неправильных ответов;
- процент правильных ответов;
- последовательность всех заданий;
- ответ тестируемого;
- правильный ответ для ошибочных и неотвеченных заданий.

Протокол можно сохранить кнопкой **«Скачать протокол»** в формате `.txt`.

## Технологии

Проект намеренно сделан максимально простым и автономным:

- **HTML5** — структура приложения;
- **CSS3** — интерфейс и адаптивность;
- **JavaScript (ES6+)** — генерация уникального пула заданий, проверка ответов, управление очередью, статистика и экспорт протокола.

Внешние JavaScript-библиотеки и серверная часть не используются.

## Требования

- Windows 11 или современная настольная ОС;
- современный браузер с поддержкой HTML5/ES6 и `Blob` API.

Подойдут актуальные версии Microsoft Edge, Google Chrome, Mozilla Firefox и другие современные браузеры.

## Безопасность и приватность

Приложение полностью локальное:

- не отправляет ответы в интернет;
- не использует внешние API;
- не собирает статистику;
- не требует аккаунта;
- не содержит серверной части.

Все ответы и результаты существуют только в текущей вкладке браузера.
