# ✕ Таблица умножения и ÷ деления

Небольшое автономное веб-приложение для тренировки таблицы умножения и связанных с ней примеров на деление.

Приложение не требует установки, сервера, Node.js, Python или других зависимостей: достаточно открыть `multiplication_test.html` в современном браузере на Windows 11.

## Возможности

- 🎯 Настраиваемое количество вопросов.
- ✕ Примеры на умножение чисел от **1 до 9**.
- ÷ Примеры на деление результатов умножения чисел от **1 до 9**.
- 🔀 Случайная генерация заданий.
- 🧠 При ошибке автоматически добавляются **2 дополнительных вопроса** для закрепления.
- 📊 Живой прогресс: количество выполненных и оставшихся вопросов.
- ⏹ Возможность завершить тест досрочно.
- 🏁 Автоматическое завершение после ответа на последний вопрос.
- 📈 Итоговая статистика:
  - всего вопросов;
  - правильных ответов;
  - неправильных ответов;
  - процент правильных ответов.
- 📝 Подробный протокол прохождения теста.
- 💾 Экспорт протокола в обычный `.txt` файл.
- ⌨️ Ответ можно отправлять клавишей **Enter**.
- 📱 Адаптивная вёрстка для небольших экранов.
- 🌙 Тёмный интерфейс без внешних библиотек и CDN.

## Как запустить

1. Скачайте репозиторий.
2. Откройте файл `multiplication_test.html` двойным щелчком.
3. Приложение откроется непосредственно в браузере.

Сервер для запуска не нужен.

## Как проходит тест

### 1. Настройка

На стартовой форме задаётся количество исходных вопросов. Можно выбрать один или оба типа заданий:

- умножение;
- деление.

### 2. Прохождение

Задания генерируются случайным образом. Для каждого вопроса отображается выражение и поле для ответа.

После отправки ответа приложение сразу показывает результат:

- `✓` — ответ правильный;
- `✗` — ответ неправильный, рядом показывается правильный результат.

При неправильном ответе в тест добавляются два новых задания.

### 3. Завершение

Тест заканчивается автоматически, когда отвечены все оставшиеся вопросы, либо вручную по кнопке **«Завершить»**.

После этого отображается итоговая статистика и подробный протокол.

## Протокол

Протокол содержит:

- дату и время прохождения;
- общее количество вопросов;
- количество правильных и неправильных ответов;
- процент правильных ответов;
- последовательность всех заданий;
- ответ тестируемого;
- правильный ответ для ошибочных заданий.

Протокол можно сохранить кнопкой **«Скачать протокол»** в формате `.txt`.

## Технологии

Проект намеренно сделан максимально простым и автономным:

- **HTML5** — структура приложения;
- **CSS3** — интерфейс и адаптивность;
- **JavaScript (ES6+)** — генерация заданий, проверка ответов, статистика и экспорт протокола.

Внешние JavaScript-библиотеки и серверная часть не используются.

## Требования

- Windows 11 или современная настольная ОС;
- современный браузер с поддержкой HTML5/ES6 и `Blob` API.

Подойдут актуальные версии Microsoft Edge, Google Chrome, Mozilla Firefox и другие современные браузеры.

## Особенности реализации

Все данные теста находятся только в памяти браузера. После закрытия страницы результаты не сохраняются.

Количество исходных вопросов ограничено интерфейсом диапазоном **5–200**. Дополнительные вопросы, возникающие из-за ошибок, увеличивают фактическое количество заданий сверх установленного исходного количества.

Для защиты от бесконечного роста теста в текущей реализации предусмотрен технический предел количества автоматически добавляемых вопросов.

## Безопасность и приватность

Приложение полностью локальное:

- не отправляет ответы в интернет;
- не использует внешние API;
- не собирает статистику;
- не требует аккаунта;
- не содержит серверной части.

Все ответы и результаты существуют только в текущей вкладке браузера.
